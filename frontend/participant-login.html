ARENA POLICY

Hackathon Rules & Guidelines

Please read carefully before starting your development sprint

01

GitHub Repository Policy

A new GitHub repository must be created only after entering the competition. All code and commits must be pushed strictly during the active sprint window.
02

Pre-written Code Prohibition

Pre-written or previously developed proprietary projects are strictly prohibited. Open-source libraries, packages, and frameworks are fully permitted.
03

Competition Time Window

The competition runs for exactly 2 hours 30 minutes (150 minutes). The sprint timer begins counting down upon accessing the dashboard. Submissions lock at 00:00:00.
04

Final Submission Requirements

The final deliverable must be a functional web application with both an accessible public GitHub repository URL and a live deployed cloud URL (e.g. Vercel, Netlify).
05

Technology Stack Freedom

Teams have complete freedom over tech stack choices: React, Vue, Svelte, Next.js, Flask, FastAPI, Node.js, Express, Tailwind, or vanilla modern JavaScript.
06

AI Prompts Transparency Audit

Teams are required to log all prompts given to AI assistants (Gemini, Claude, GPT-4o, Cursor) in the dashboard prompt console. Prompts are scored for craftsmanship and AI synergy.
07

Fair Play & Integrity

Cross-team collusion, plagiarism, or malicious tampering will lead to immediate disqualification. All members must be registered in the official team roster.
08

Judges' Decision is Final

Evaluation will be conducted by the official jury panel using a multi-criteria rubric (Technical Complexity, UI/UX Craftsmanship, Innovation, and AI Prompt Engineering).
