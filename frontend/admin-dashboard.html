Gemini AI Telemetry Evaluation Architecture

Automated prompt evaluations run across these 5 technical pillars to objectively benchmark engineering skill.

Max Scale
50 / 50 PTS

1. Problem Understanding & Requirements

0 - 10 PTS

Evaluates comprehensive comprehension of the challenge domain, user personas, and core business logic.

  • Multi-role mapping (Coordinator, HOD, Dean, ITC Admin)
  • Multi-level approval chains and status states
  • Rejection flows with audit explanations
  • Venue, equipment, and resource conflict detection

2. Technical Depth & Architectural Precision

0 - 10 PTS

Evaluates engineering rigor, database schema design, and exact system specifications.

  • Explicit relational/document database schemas & contracts
  • REST / GraphQL API specifications & status codes
  • JWT / RBAC security models & authorization gates
  • State machines, transaction isolation, and error boundaries

3. Prompt Engineering Technique

0 - 10 PTS

Evaluates structured prompt design, framing discipline, and instruction fidelity.

  • Persona framing (e.g. "Act as a Senior System Architect")
  • Explicit negative constraints ("Strictly avoid dummy mocks")
  • Strict output formatting (JSON schemas, Markdown, step-by-step)
  • Chain-of-thought verification & edge case guidance

4. Strategic & Intentional AI Usage

0 - 10 PTS

Evaluates architectural guidance vs. naive copy-paste code requests.

  • System decomposition and component boundaries
  • Architecture trade-off queries and security reviews
  • Modular iterative prompts rather than monolithic dumps
  • Active technical steering of model outputs

5. Contextual Alignment with Scenario

0 - 10 PTS

Evaluates responsiveness to dynamic live hackathon conditions and constraints.

  • Mid-event additional resource requests
  • Dynamic venue reallocation without constraint violations
  • Continuous state updates and audit trail compliance
  • Emergency override and fallback protocols
