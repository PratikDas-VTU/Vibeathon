Rules & Guidelines

Please read carefully and follow all rules

01

GitHub Repository Policy

A new GitHub repository must be created only after entering the college campus. All development work must be pushed to the repository strictly during the competition period.

02

Pre-written Code Prohibition

Pre-written or previously developed projects are strictly prohibited. Only code written during the event duration will be considered for evaluation.

03

Competition Time Window

The competition will run for a fixed development duration. Coding must begin only after the official start announcement by the organizers.

04

Final Submission Requirements

The final submission must be a working AI-based web application or web dashboard that runs either locally or directly in a web browser.

05

Technology Stack Freedom

Teams are free to use any web technology stack including HTML, CSS, JavaScript, React, Flask, Node.js, or similar technologies to implement their solution.

06

Fair Play & Collaboration Policy

Cross-team collaboration, code sharing, or idea exchange between teams is strictly prohibited and will result in disqualification.

07

Innovation & Conduct

Teams are encouraged to focus on innovation, creativity, and practical problem-solving rather than purely theoretical solutions. Any form of malpractice or rule violation will lead to immediate disqualification, and the judges’ decision will be final.

Frequently Asked Questions

Everything you need to know about participating in the AI-Assisted Vibeathon

Q1

What is the AI-Assisted Vibeathon 2026?

Organized by the School of Computing — Cyber Security Department, the Vibeathon is an intense, fast-paced sprint on 16 September 2026. Builders utilize next-generation AI tools to transform concepts into production-grade, secure applications in just 2 to 3 hours.

Q2

Which AI tools and models are permitted?

Participants are empowered to use any AI coding assistants and LLMs including GitHub Copilot, Cursor, ChatGPT, Claude, Gemini 2.5, v0, Bolt, and open-source models. All queries and prompt logs must be submitted to the platform for telemetry evaluation.

Q3

How does prompt logging and immutable timestamping work?

Each team has access to the Participant Arena where prompts are logged in real-time. Every prompt entry receives an immutable cryptographic timestamp. The platform automatically assesses prompt engineering depth, context retention, and problem-solving trajectory.

Q4

What are the final deliverables required for submission?

Teams must submit:
1. A public GitHub repository created strictly during the competition on campus with transparent commit history.
2. A live deployed application URL (Vercel, Render, Netlify, Cloudflare Pages, etc.) or verified localhost prototype.
3. Full session AI prompt logs.

Q5

How will projects be scored by the jury?

Submissions undergo dual evaluation: automated prompt telemetry scoring powered by Gemini 2.5 Flash, combined with a comprehensive expert jury audit evaluating Functional Completeness, Cyber Security safeguards, UI/UX polish, and AI prompt mastery.
